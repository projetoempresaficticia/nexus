Dúvida: $ARGUMENTS

1. Procure a resposta nos docs do projeto (`docs/`). Se já houver decisão em DECISOES.md, siga-a e pare.
2. Verifique se uma skill do projeto cobre o tema (angular-developer, Supabase). Rode `npx skills find <termos>` para outras skills e leia as descrições (não instale).
3. Se o Hermes estiver disponível (ver FERRAMENTAS.md), peça uma comparação de opções.
4. Pesquise em fontes oficiais (lista em FERRAMENTAS.md) com WebSearch/WebFetch — 2 a 4 consultas.
5. Critérios: simples para quem tem experiência básica, gratuito, bem documentado, compatível com Angular + Supabase + GitHub Pages, leve no bundle, coerente com NAO_FAZER.md.
6. Apresente 2–3 opções numa tabela (prós, contras, esforço), com a recomendada marcada e uma linha de justificativa cada, e as fontes.
7. Depois que o Germano escolher, registre em `docs/DECISOES.md` (data · decisão · alternativas · fonte · motivo).
